Data source & thresholds

Link your sensor feed and choose limits that make sense for your motor

Live data only: no synthetic readings are generated; until a valid ThingSpeak channel is connected the dashboard shows an unconnected state. ThingSpeak fields: 1 = motor temperature (°C), 2 = vibration RMS (g), 3 = device status (0 normal, 1 warning, 2 fault), 4 = current (A, optional), 5 = motor RPM (optional). Fields 4–5 may stay empty. Default thresholds follow the project report (60 / 75 °C, 2 / 3 A); the vibration limits are starting values to tune on your own rig. A Read API key is safer than a Write key in a browser. Settings are stored in this browser only. This is a monitoring prototype, not a certified safety system.
